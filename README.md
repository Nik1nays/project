# Проект Bank card

## Описание:

Проект Bank card маскирует и сортирует банковские карты

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Nik1nays/project.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:
1. Откройте проект 
2. Выберите нужную для вас функцию по описанию
3. Вставьте свои данные 
4. Наслаждайтесь результатом
